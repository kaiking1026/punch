# 今日打卡 PWA

一个离线优先、只依赖浏览器本地存储的个人打卡和日程记录工具。

## 现在已经有的功能

- 首页点击项目即可打卡
- 右上角 `+` 新建打卡项目，并选择颜色和图形
- 第二页日历按日期显示打卡标记和日程内容
- 点击日历日期可补打卡、添加日程、查看当天明细
- 日程新增、完成、删除
- 本地离线保存
- JSON 导入导出备份
- Service Worker 离线缓存

## 最低成本使用方式

如果只是你自己用，最省钱的方式是把这套静态文件部署到免费的静态托管：

- GitHub Pages
- Cloudflare Pages
- Netlify

这样通常可以做到长期 `0 成本`。

## 本地预览

PWA 的安装和 Service Worker 需要通过 `localhost` 或 `HTTPS` 访问，不建议直接双击 `index.html`。

如果你电脑上有任意静态服务器，可以在当前目录启动一个，例如：

```powershell
python -m http.server 8080
```

然后在浏览器里打开：

```text
http://localhost:8080
```

## 手机上安装

### iPhone

1. 用 Safari 打开部署后的网址
2. 点分享
3. 选择“添加到主屏幕”

### Android

1. 用 Chrome 打开部署后的网址
2. 点击“安装应用”或“添加到主屏幕”

## 数据说明

- 所有数据默认存储在当前浏览器本地
- 清理浏览器数据后，本地记录会丢失
- 换设备前建议先用“导出数据”备份
